Approach

How I run an IT controls review.

The same five steps I followed in the case study, from scoping to follow-up.

  1. 1 · Understand and scope

    Systems in scope (SAP S/4HANA, the HSM API console, Active Directory), audit period and the risks each control must address.

  2. 2 · Walk through the process

    Map the flow in BPMN and confirm where each control sits and who performs it.

  3. 3 · Test every record

    Script each control test, prove it on hand-built pass and fail cases, then run it on the full population.

  4. 4 · Rate and report

    Rate each exception by risk, write the finding in plain language and agree the action, owner and due date.

  5. 5 · Follow up

    Re-run the tests on fresh evidence so a fixed control is proven fixed, not just reported fixed.
